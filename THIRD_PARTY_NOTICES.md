# Third-party materials and provenance

## Fonts

The project bundles original font sources in skills/photo-story-magazine/assets/fonts/:

| Source | License file |
|---|---|
| Source Han Serif CN VF | SourceHanSerif-LICENSE.txt |
| Noto Sans SC VF | NotoSansSC-OFL.txt |
| Roboto Condensed VF | RobotoCondensed-OFL.txt |

These fonts retain their SIL Open Font License 1.1 notices and are excluded from the project's MIT re-licensing. Copyright, upstream project links, versions and SHA-256 are recorded in sources.json. Prepared static/subset derivatives receive distinct FieldKit family names and copies of their font licenses.

## Images and examples

The four finished cover examples are original AI-generated photorealistic concept artworks, not photographs of identified real sites. Generation provenance, dimensions, checksums, recipes and prompts are included in the cover skill. They contain the sample publication name 行见, which is not the application name or a mandatory user publication title.

The layout specimen's graphics, text and compositions are original teaching examples. The repository contains no user travel photographs, reference magazine page screenshots, extracted magazine fonts or reference magazine PDFs. Original research notes cite publication dates and page numbers; the underlying privately reviewed source material is not distributed.

The MIT license covers this project's original code and documentation and the original example material to the extent rights are held. Third-party font licenses remain controlling for the bundled font software.
